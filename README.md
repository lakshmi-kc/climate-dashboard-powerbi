# 🌦️ Climate Dashboard — Power BI

A data visualization project connecting Python to MySQL and building a Power BI dashboard for Indian climate data.

---

## 📌 Project Overview

This project loads Indian climate data (2024–2025) from a MySQL database using Python and SQLAlchemy, then visualizes it using Power BI to create an interactive climate dashboard.

---

## 📂 Dataset

- Source: MySQL database
- Table: indian_climate_dataset_2024_2025
- Coverage: Indian climate records for 2024–2025

---

## 🛠️ Tools & Libraries

- **Database:** MySQL, mysql.connector
- **Data Loading:** Python, SQLAlchemy, Pandas
- **Visualization:** Power BI Dashboard

---

## 🔍 Project Workflow

1. MySQL Connection — connect using mysql.connector and SQLAlchemy
2. Data Extraction — load climate table into Pandas DataFrame
3. Data Cleaning and Preparation
4. Export to Power BI — connect Power BI to MySQL
5. Dashboard Creation — interactive climate visualizations
